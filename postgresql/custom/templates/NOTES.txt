PostgreSQL {{ .Values.image.tag | default .Chart.AppVersion }} (alpine) — release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

1. Wait for the pod to be Ready (one replica, single-writer):

   kubectl -n {{ .Release.Namespace }} rollout status statefulset/{{ $fullName }} --timeout=5m

   A cold volume runs initdb first; watch it with:

   kubectl -n {{ .Release.Namespace }} logs {{ $fullName }}-0 -f

2. Connect from inside the cluster — host {{ $fullName }}.{{ .Release.Namespace }}.svc,
   port {{ $port }}, user {{ .Values.auth.username }}, database {{ .Values.auth.database }}:

   kubectl -n {{ .Release.Namespace }} run psql --rm -it --restart=Never \
     --image={{ include "postgresql.image" . }} -- \
     psql --host {{ $fullName }}.{{ .Release.Namespace }}.svc --port {{ $port }} \
          --username {{ .Values.auth.username }} --dbname {{ .Values.auth.database }}

   The password is under key {{ .Values.auth.secretKey }} of Secret {{ $secret }}, which this
   chart never rendered into a manifest. Read it with:

   kubectl -n {{ .Release.Namespace }} get secret {{ $secret }} \
     -o jsonpath='{.data.{{ .Values.auth.secretKey }}}' | base64 -d

   kubectl -n {{ .Release.Namespace }} exec {{ $fullName }}-0 -- sh -c 'echo "$PGDATA"; ls "$PGDATA" | head'
